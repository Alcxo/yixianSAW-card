壹线样卡 · 手机独立版（iOS 浏览器）
====================================

【它是什么】
  把「花边照片 → 公司样卡」整套算法搬进了浏览器：抠图、排版、写字、出 JPG
  全部在 iPhone 的 Safari 里算，**不用开电脑、不用连电脑**。
  和电脑版是同一份 Python 代码（Pillow / numpy 编译成 WebAssembly 跑），
  所以出卡效果和电脑版一致；手机上跑不了 AI 超分（Real-ESRGAN 需要显卡），
  只有普通锐化。

【怎么装到手机上（一次）】
  办法一：放到免费的静态网站（推荐，装好后随时能用、能离线）
    1. 把这个文件夹整个上传到任意静态托管，例如：
       · Cloudflare Pages（拖拽上传，免费，国内多数可访问）
       · GitHub Pages（新建仓库 → 上传这些文件 → Settings → Pages）
       · 你自己的服务器 / 对象存储静态网站 / 宝塔面板
    2. 手机 Safari 打开那个网址（https://…）。
    3. 点底部「分享」→「添加到主屏幕」，桌面就会多一个「壹线样卡」图标。
    4. 第一次打开会下载约 16 MB 的引擎（10~20 秒），之后从缓存秒开，断网也能用。

  办法二：先在电脑上试（只用来验收效果，不能离线）
    在电脑这个文件夹里执行：  python -m http.server 8000
    然后手机连同一个 Wi-Fi，Safari 打开 http://电脑IP:8000
    （这样能用，但 http 下不能「添加到主屏幕」离线缓存，长期用还是办法一）

【每天怎么用】
  1. 点开桌面上的「壹线样卡」
  2. 「从相册选择 / 拍照」→ 可以一次选十几张
  3. 每张照片下面把型号改成花型号（手机拍的文件名是 IMG_1234，点一下就能改）
  4. 要不要选规格表都行（从「文件」里选 xlsx / xls / csv，自动按编号取花宽/花高）
  5. 选排版（自动 / 满幅 / 单条 / 并列），拉一下「有色占比」
  6. 点底部「生成样卡」，等进度条走完
  7. 存图：点「保存」或「保存全部到相册」→ 分享面板里选「存储图像」；
     或者在图片上长按 →「存储图像」

【速度参考】
  iPhone 12 及以上：一张大约 3~6 秒（12MP 照片，出 A4 300dpi）
  第一次打开要加载引擎，多等 10~20 秒；之后秒开。

【文件说明】
  index.html            页面
  app.css / app.js      界面与流程
  worker.js             后台线程：加载引擎、逐张出卡
  py/bridge.py          浏览器版调用现有算法的桥
  py/swatch/            出卡算法（和电脑版同一份）
  vendor/               Python 运行时（Pyodide）+ numpy + Pillow + xlrd
  assets/template.jpg   默认模板（就是 模版.jpg）
  assets/template.json  模板版面识别结果（虚线框、填写位、字号）
  assets/icon-*.png     桌面图标
  sw.js / manifest      离线缓存 + 添加到主屏幕

【换模板 / 换规格表】
  页面上「换模板」可以直接选新图片，程序会自动重新识别虚线框和填写位。
  识别不准（框太怪）时，还是建议用电脑版「检测模板」生成 profile 后再换。

【隐私】
  照片只在你手机里处理，不上传任何服务器；托管页只有程序文件。
